# PlanAmWell

Combined snapshot of the PlanAmWell platform's four projects:

- [`backend/`](./backend) — Node.js/Express API
- [`web/`](./web) — Next.js web app
- [`frontend/`](./frontend) — React Native (Expo) mobile app
- [`Admin/`](./Admin) — Next.js admin dashboard

This `main` branch holds a single combined snapshot of each project's current code for easy browsing. Each project's full, detailed commit history is preserved separately on its own branch in this repo:
